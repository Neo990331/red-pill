# 红药丸 Red Pill

> 用信息作为底层语言，研究身、心、环境的运作方式，建立让人能据此行动的协议。

---

## 这是什么

一个人的长期研究项目。

核心假设：信息是比物质更基本的现实层面。如果这个假设成立，那么身体、意识和环境——人每时每刻都在其中运作的三个系统——在信息层面有可读取的结构。读取这些结构，就有可能知道此刻正在发生什么，以及该怎么做。

这个项目做两件事：研究这些结构（它们是什么、怎么运作），同时把理解压缩成可执行的协议（知道了之后，具体怎么做）。两者不是先后关系，而是一个循环——研究产生理解，理解变成动作，动作在实践中被验证，验证产生新的理解。

---

## 身、心、环境

所有工作围绕三个界面展开。

**身** — 身体作为信息系统。体感、气、能量状态、生物节律。身体在每个时刻都在输出信号，这些信号是系统对当前状态的实时报告。

**心** — 意识与认知。注意力、感知带宽、信念结构、自动化反应模式。心既是观察的工具，也是被观察的对象。

**环境** — 你所处的场。时空节律、五行格局、信息耦合。环境不是被动的背景，而是一个有规律的、可读取的编码系统。

三个界面在每一个时刻同时运作、相互影响。研究的指向是理解它们各自和交互的运作方式；协议的指向是让人能在这个交互中做出更精准的回应。

---

## 研究与协议

**研究**回答"是什么"和"为什么"。跨学科地连接物理学、神经科学、东方哲学（五行、易、命理）、AI 与意识研究——不是为了把它们融合成一个学科，而是因为它们经常在底层描述同一个结构的不同面。研究的工作是找到这些映射，建立统一的解读框架。

**协议**回答"怎么做"。把研究中的理解压缩成可执行的东西——当你读出自己处在某种状态或模式中，下一步做什么。协议不是理论推演，它必须在自己身上跑通。
